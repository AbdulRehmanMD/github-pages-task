\# GitHub Pages Static Website



\## Objective

Deploy a static website using GitHub Pages.



\## Technologies

\- HTML

\- CSS

\- Git and GitHub

\- GitHub Pages



\## Project

Created a responsive DevOps portfolio website featuring About Me, Skills, DevOps Projects, and Goals sections.



\## Live Website

https://abdulrehmanmd.github.io/github-pages-task/



\## Deployment

1\. Created `index.html`.

2\. Initialized a Git repository.

3\. Pushed the code to GitHub.

4\. Enabled GitHub Pages from the `main` branch and root folder.

5\. Verified the published website in a browser.
